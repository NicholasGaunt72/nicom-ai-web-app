How we integrate AI

The architecture behind every Nicom web app

AI is not a widget bolted on at the end. It sits in the server layer, where it can read your business data safely and take action.

  1. 01

    Interface

    Chat, forms, voice and buttons in the browser. Fast, accessible, mobile-first.

  2. 02

    Serverless API

    Vercel functions in /api hold the API keys, validate input and limit abuse.

  3. 03

    Model + context

    A language model gets your services, prices, FAQs and tone as context, and returns text or structured JSON.

  4. 04

    Actions

    Results flow into CRM, email, WhatsApp, calendars and dashboards through automations.

api/chat.jssimplified
// Runs on Vercel. The API key never reaches the browser.
export default async function handler(req, res) {
  const { messages } = req.body;
  const reply = await complete({
    system: BUSINESS_CONTEXT,          // services, hours, tone, rules
    messages: messages.slice(-12),     // short-term memory
  });
  await crm.logConversation(reply);  // optional action step
  res.json({ reply });
}
